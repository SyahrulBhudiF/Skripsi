2. Input ROI

Notebook memakai 3 ROI:

  • mata_alis_kanan
  • mata_alis_kiri
  • mulut

Setiap ROI diambil dari landmark wajah, lalu di-resize agar ukuran konsisten.

'mata_alis_kanan': list(range(42, 48)) + list(range(22, 27))
'mata_alis_kiri': list(range(36, 42)) + list(range(17, 22))
'mulut': list(range(48, 68))

3. POC-ABS → magnitude per ROI

Untuk setiap pasangan frame berurutan, notebook membandingkan ROI frame sebelumnya dan frame saat ini.

poc = POC(roi_prev, roi_curr, config.block_size)
vec = Vektor(poc.getPOC(), config.block_size)
quad_data = Quadran(vec.getVektor()).getQuadran()
magnitudes = [float(block[4]) for block in quad_data]

block[4] adalah magnitude gerak tiap block. Lalu semua magnitude block dirata-rata:

roi_values[region_name] = np.mean(magnitudes)

4. Mean magnitude → magnitude signal

Setelah tiap ROI punya nilai magnitude, notebook merata-ratakan 3 ROI:

raw_value = np.mean(list(roi_values.values()))

Nilai raw_value per frame-pair dikumpulkan menjadi deret:

magnitude signal = [0.02, 0.03, 0.10, 0.42, 0.18, ...]

Makna: semakin tinggi nilai, semakin besar gerakan wajah pada frame-pair itu.

5. Smoothed signal

Raw signal biasanya noisy. Maka dipakai ApexSmoother.smooth().

smoothed = ApexSmoother.smooth(magnitudes)

Smoother memakai Savitzky-Golay filter. Window adaptif: sekitar 5% panjang sinyal, ganjil, dibatasi maksimal 31.

Tujuan: bentuk puncak event lebih stabil, noise kecil tidak langsung dianggap apex.

6. Threshold

Threshold dipakai untuk menentukan peak yang cukup tinggi.

height_threshold = signal_arr.mean() + signal_arr.std()

Artinya: peak harus lebih tinggi dari rata-rata sinyal + 1 standar deviasi.

Kalimat presentasi: “Threshold memisahkan gerakan biasa dari kandidat gerakan ekspresif yang lebih kuat.”

7. Peak detection = apex

Apex dicari dari smoothed signal menggunakan ApexPhase.find_top_k_apex().

apex_indices = detector.find_top_k_apex(smoothed, k=config.top_k_apex, height=height_threshold)

Syarat peak:

  • cukup tinggi: lolos height_threshold
  • cukup menonjol: prominence_threshold
  • tidak terlalu dekat dengan peak lain: distance/merge threshold

Apex = frame/signal index dengan magnitude puncak event.

8. Phase boundary = onset dan offset

Setelah apex ketemu, notebook mencari batas kiri dan kanan event:

phases = detector.find_phase(smoothed, apex_indices)

Logika sederhana:

  • dari apex jalan ke kiri → cari lembah/batas turun → onset
  • dari apex jalan ke kanan → cari lembah/batas turun → offset
  • pakai cutoff ratio agar batas tidak terlalu jauh

Onset = awal sinyal naik menuju apex. Offset = sinyal selesai turun setelah apex.

9. Duration filtering

Tidak semua peak valid. Event terlalu pendek dibuang:

duration = phase['end'] - phase['start']
if duration < config.min_phase_duration:
    continue

Tujuan: noise sesaat tidak dianggap micro-expression event.

10. Output frame onset–apex–offset

Signal index dikonversi ke frame index:

def signal_index_to_frame_index(signal_index):
    return signal_index + 1

Kenapa +1? Karena magnitude index 0 berasal dari perbandingan frame 0 → frame 1, jadi event signal index 0 ditandai pada frame 1.

Output metadata:

onset_frame, apex_frame, offset_frame, duration

Narasi presentasi 60 detik

“Spotting dimulai dari tiga ROI wajah: mata-alis kanan, mata-alis kiri, dan mulut. Untuk setiap pasangan frame berurutan, POC-ABS menghitung pergerakan block pada tiap ROI. Magnitude block dirata-rata menjadi nilai magnitude ROI, lalu tiga ROI dirata-rata menjadi magnitude signal.”

“Magnitude signal kemudian dihaluskan agar noise kecil tidak dianggap event. Dari smoothed signal, threshold dihitung menggunakan mean plus standar deviasi. Peak yang melewati threshold dan cukup menonjol dipilih sebagai apex.”

“Setelah apex ditemukan, sistem mencari batas kiri dan kanan phase untuk menentukan onset dan offset. Event yang durasinya terlalu pendek dibuang. Hasil akhirnya adalah frame onset, apex, dan offset untuk setiap event yang terdeteksi.”
