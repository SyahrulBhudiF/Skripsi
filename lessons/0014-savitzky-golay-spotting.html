Savitzky-Golay Filter untuk Spotting

Target: paham filter Savitzky-Golay itu apa, cara kerja, dan kenapa cocok untuk sinyal onset–apex–offset.

Sumber: SciPy savgol_filter docs, Savitzky & Golay 1964.

1. Masalahnya apa?

Magnitude signal dari POC-ABS sering noisy:

[0.10, 0.12, 0.09, 0.40, 0.36, 0.42, 0.11]

Noise kecil bisa membuat peak palsu. Kalau langsung cari apex dari raw signal, event bisa salah.

Maka sinyal dihaluskan dulu.

2. Savitzky-Golay itu apa?

Savitzky-Golay = smoothing dengan fitting kurva polynomial lokal.

Untuk setiap titik sinyal, filter mengambil beberapa titik tetangga dalam window, lalu mencari kurva polynomial kecil yang paling cocok. Nilai tengah diganti dengan nilai dari kurva itu.

Bukan sekadar rata-rata. Ia mencoba mengikuti bentuk lokal sinyal.

3. Cara kerja step-by-step

Ambil window ganjil
Fit polynomial
Ambil nilai tengah kurva
Geser window
Hasil smoothed signal

Contoh window length = 5, polyorder = 2:

raw:        [0.10, 0.13, 0.50, 0.15, 0.12]
window:       └──────── 5 titik ────────┘
fit:       kurva kuadrat lokal
output:    nilai tengah hasil kurva

Proses ini diulang untuk semua titik.

4. Apa itu window_length?

window_length = jumlah titik yang dilihat sekaligus.

  • Window kecil → smoothing ringan, masih sensitif noise.
  • Window besar → smoothing kuat, tapi bisa meratakan apex.

Di kode kamu:

window_length = int(length * 0.05)
if window_length % 2 == 0: window_length += 1
window_length = max(5, min(window_length, 31))

Jadi window adaptif: sekitar 5% panjang sinyal, harus ganjil, minimal 5, maksimal 31.

5. Kenapa window harus ganjil?

Karena filter butuh titik tengah yang jelas.

Window 5
2 kiri + 1 tengah + 2 kanan
Window 6
tidak punya satu titik tengah jelas

Itu sebabnya kode menaikkan window genap menjadi ganjil.

6. Apa itu polyorder?

polyorder = derajat kurva polynomial yang dipakai.

  • 2 = kurva kuadrat, bisa menangkap lengkungan sederhana.
  • 3 = kubik, lebih fleksibel.
  • 4 = lebih fleksibel lagi, tapi jangan terlalu tinggi.

Di kode kamu:

if window_length <= 7: polyorder = 2
elif window_length <= 15: polyorder = 3
else: polyorder = 4

Aturan ini menjaga kurva cukup fleksibel tapi tidak terlalu mengikuti noise.

7. Kenapa bukan moving average biasa?

Moving average merata-ratakan nilai. Akibatnya peak bisa turun dan bentuk apex bisa melebar.

Savitzky-Golay fitting kurva lokal. Ia biasanya lebih baik menjaga bentuk puncak, tinggi puncak, dan trend lokal.

Moving average
halus, tapi peak gampang gepeng
Savitzky-Golay
halus, tapi bentuk peak lebih terjaga

8. Kenapa dipilih untuk spotting?

Spotting butuh dua hal sekaligus:

  1. Noise kecil harus dikurangi.
  2. Apex tidak boleh hilang/gepeng berlebihan.

Savitzky-Golay cocok karena ia menghaluskan sinyal tetapi tetap mempertahankan bentuk puncak. Ini penting karena apex dicari dari peak.

Kalimat presentasi:

“Savitzky-Golay dipilih karena dapat mengurangi noise pada magnitude signal sambil mempertahankan bentuk puncak, sehingga deteksi apex lebih stabil.”

9. Di notebook terjadi di mana?

smoothed = ApexSmoother.smooth(magnitudes)

Lalu smoothed signal dipakai untuk:

  • menghitung threshold mean + std
  • mendeteksi apex dengan find_top_k_apex
  • mencari onset-offset dengan find_phase

Jadi smoothing memengaruhi seluruh proses event spotting.

10. Risiko kalau parameter salah

  • Window terlalu kecil: noise masih banyak, peak palsu.
  • Window terlalu besar: apex bisa terlalu rata, onset-offset melebar.
  • Polyorder terlalu rendah: bentuk puncak kurang terjaga.
  • Polyorder terlalu tinggi: filter bisa ikut noise.

Makanya kode memakai parameter adaptif, bukan angka tetap.

Soal ABC

1. Savitzky-Golay menghaluskan sinyal dengan cara...

  1. menghapus semua peak
  2. fitting polynomial lokal
  3. mengubah frame jadi RGB

2. Window_length berarti...

  1. jumlah titik dalam window
  2. jumlah ROI wajah
  3. jumlah kelas model

3. Kenapa window harus ganjil?

  1. agar ada titik tengah
  2. agar file bisa dibuka
  3. agar label berubah

4. Dibanding moving average, Savitzky-Golay lebih dipilih karena...

  1. lebih menjaga bentuk peak
  2. selalu membuat nilai nol
  3. tidak butuh sinyal

5. Kalau window terlalu besar, risiko utamanya...

  1. apex menjadi terlalu rata
  2. frame tidak terbaca
  3. ROI jadi hilang
