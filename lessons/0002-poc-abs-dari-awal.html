POC-ABS dari Awal

Tujuan: bisa jelaskan teori POC-ABS dari nol untuk presentasi skripsi, lalu hubungkan ke kode notebook.

1. Masalah yang diselesaikan

Micro-expression sangat cepat dan halus. Yang dicari bukan “gambar wajahnya mirip atau tidak”, tapi ada pergeseran kecil di area wajah tertentu atau tidak.

POC-ABS dipakai untuk estimasi gerakan lokal pada ROI wajah. Paper Rosiani et al. menyebut POC-ABS membandingkan block pada frame berurutan; jika block berbeda, sistem menghasilkan motion vector. Jika block identik, tidak ada motion vector.

Sumber utama: Rosiani et al. 2020, Section 2–3.2, PDF.

3. Intuisi POC

Bayangkan dua potongan gambar kecil: block dari frame t dan block dari frame t+1.

  • Kalau dua block sama persis → puncak POC tinggi di tengah → dianggap tidak bergerak.
  • Kalau block bergeser → puncak POC pindah posisi → posisi puncak menunjukkan arah pergeseran.

POC memakai informasi fase dari Fourier, bukan amplitudo mentah. Karena itu ia kuat untuk image matching dan displacement estimation.

4. Apa arti “ABS”?

ABS = All Block Search. Namun di paper ini, bukan full-search ke banyak posisi seperti POC-FS.

POC-ABS membandingkan block current frame dengan block reference frame pada posisi block yang sama. Tujuannya bukan mencari match paling optimal di seluruh search window, tapi mendeteksi apakah block itu mengalami pergeseran.

Ini membuat POC-ABS lebih ringan. Paper melaporkan POC-ABS lebih cepat daripada POC-FS karena search-nya lebih sederhana.

5. Output fitur

Setelah puncak korelasi ditemukan, pergeseran dijadikan motion vector. Dari vector itu diambil fitur:

  • X: komponen horizontal
  • Y: komponen vertikal
  • θ / theta: sudut arah gerak
  • Magnitude: besar gerak

Di kode kamu:

poc = POC(baseline_gray[comp], gray, block_size)
vec = Vektor(poc.getPOC(), block_size)
quad = Quadran(vec.getVektor()).getQuadran()

row[f'{comp}_x{block_id}'] = block[1]
row[f'{comp}_y{block_id}'] = block[2]
row[f'{comp}_t{block_id}'] = block[3]
row[f'{comp}_m{block_id}'] = block[4]

6. Narasi presentasi 45 detik

“POC-ABS digunakan untuk mengekstraksi fitur gerakan halus pada ROI wajah. Pertama, area wajah seperti mata dan mulut diambil dari dua frame, yaitu frame t dan frame t+1. Area ROI dibagi menjadi beberapa block kecil.”

“Setiap block dibandingkan menggunakan Phase-Only Correlation. Jika block tidak bergeser, puncak korelasi berada di tengah. Jika ada pergeseran, posisi puncak berubah, sehingga arah dan besar pergeseran dapat dihitung.”

“Pergeseran itu kemudian dibentuk menjadi vektor gerak. Dari tiap vektor diambil fitur X, Y, sudut θ, dan magnitude. Fitur inilah yang disimpan sebagai representasi gerakan micro-expression.”
