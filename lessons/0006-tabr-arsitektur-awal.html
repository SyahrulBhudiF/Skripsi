1. TABR itu apa?

TABR = retrieval-based model untuk data tabular.

Model ini tidak hanya membaca input satu sampel, tapi juga mencari sampel train yang mirip sebagai context. Context itu membantu prediksi akhir.

Kalimat presentasi:

“TABR memprediksi data tabular dengan menggabungkan representasi input dan informasi dari sampel training yang paling mirip.”

3. Mapping ke kode

  • Input data tabular: x_, berisi num, bin, cat
  • Encoder: _encode(), self.linear, self.blocks0
  • Representasi laten z: output x dari encoder
  • Retrieval key: k = self.K(...)
  • Retrieval: FAISS search pada candidate_k
  • Context: context_y_emb + self.T(k[:, None] - context_k)
  • Residual add: x = x + context_x
  • Predictor: self.blocks1 lalu self.head

4. Intuisi tiap blok

Encoder mengubah fitur mentah menjadi vektor laten.

Retrieval mencari kandidat data train yang representasinya paling dekat.

Context mengambil informasi label kandidat mirip dan selisih representasi.

Residual add menambahkan context ke representasi input.

Predictor mengubah representasi akhir menjadi output kelas/nilai.

5. Narasi presentasi 45 detik

“Model TABR menerima input data tabular berupa fitur numerik, biner, atau kategorikal. Input ini masuk ke encoder untuk membentuk representasi laten. Dari representasi tersebut, model membuat key yang digunakan untuk retrieval.”

“Pada tahap retrieval, model mencari sampel training yang paling mirip menggunakan jarak antar key. Sampel mirip ini membentuk context, yaitu informasi tambahan dari data tetangga yang relevan.”

“Context kemudian ditambahkan ke representasi input melalui residual add. Setelah itu predictor menghasilkan output akhir, misalnya kelas anxiety tinggi atau rendah.”
