2. Hubungkan diagram ke kode

Input ROI berasal dari event clip. Frame pertama clip jadi baseline. Frame berikutnya dibandingkan ke baseline.

Kode inti: extract_flatten_row(...) di notebook.

POC ada di POC(baseline_gray[comp], gray, block_size).

Di dalamnya: block ROI → Fourier → normalisasi fase → inverse Fourier → puncak korelasi.

Vektor dan fitur dibuat oleh:

Vektor(poc.getPOC(), block_size) lalu Quadran(vec.getVektor()).getQuadran().

Output per block: x, y, t / theta, m / magnitude.

3. Script presentasi 60 detik

Pada tahap ini, inputnya adalah ROI wajah seperti mulut, mata kiri, dan mata kanan. Setiap ROI dibandingkan antara frame baseline dan frame target. ROI kemudian dibagi menjadi block kecil. Untuk setiap block, sistem menghitung Phase-Only Correlation. POC bekerja di domain Fourier dan hanya memakai informasi fase, sehingga fokus pada pergeseran pola tekstur antar frame. Hasil POC berupa peta korelasi. Titik puncak pada peta ini dianggap sebagai estimasi pergeseran lokal pada block tersebut. Pergeseran itu lalu diubah menjadi vektor gerak. Dari vektor ini dihitung komponen X, komponen Y, sudut theta, dan magnitude. Nilai-nilai inilah yang diekspor sebagai fitur POC-ABS untuk setiap frame dalam event clip.
