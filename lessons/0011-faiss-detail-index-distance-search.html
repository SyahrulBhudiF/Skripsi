1. FAISS bekerja di dunia vektor

Semua data harus jadi vektor angka dulu.

FAISS tidak paham “pasien”, “anxiety”, “fitur POC”, atau “tabular”. FAISS cuma melihat angka:

query k       = [0.2, 0.8]
candidate A   = [0.1, 0.7]
candidate B   = [3.0, 2.9]
candidate C   = [0.4, 1.0]

Tugas FAISS: cari candidate mana yang jaraknya paling dekat dengan query.

2. Jarak L2 itu apa?

L2 = Euclidean distance. Versi 2D:

distance = sqrt((x1 - x2)^2 + (y1 - y2)^2)

Contoh query [0.2, 0.8] dan candidate A [0.1, 0.7]:

distance = sqrt((0.2-0.1)^2 + (0.8-0.7)^2)
         = sqrt(0.01 + 0.01)
         = 0.141

Semakin kecil jarak, semakin mirip.

3. Search top-k

Output FAISS:

distances   = [[0.141, 0.283, 3.466]]

context_idx berarti: tetangga terdekat adalah candidate ke-0, lalu ke-2, lalu ke-1.

4. Apa itu index?

Index = struktur penyimpanan vektor agar bisa dicari.

Di TABR:

self.search_index = faiss.IndexFlatL2(d_main)
self.search_index.add(candidate_k)
distances, context_idx = self.search_index.search(k, context_size)
  • d_main: panjang vektor laten.
  • candidate_k: semua vektor kandidat dari data train.
  • k: vektor query/input saat ini.
  • context_size: jumlah tetangga yang diminta.

5. Kenapa disebut Flat?

Flat berarti exact search: query dibandingkan dengan semua candidate.

Kelebihan
Hasil tepat. Tidak approximate.
Kekurangan
Kalau candidate sangat banyak, bisa berat.

Official docs menyebut IndexFlatL2 sebagai index untuk L2 search. Ia tidak butuh training index.

6. Kenapa TABR reset lalu add lagi?

self.search_index.reset()
self.search_index.add(candidate_k)

Karena candidate representation bisa berubah selama training. Encoder masih belajar, jadi candidate_k epoch/batch ini bisa berbeda dari sebelumnya.

Maka index dibersihkan, lalu diisi ulang dengan candidate terbaru.

7. Di training, kenapa diri sendiri dibuang?

Saat training, batch train sempat ditambahkan ke candidate:

candidate_k = torch.cat([k, candidate_k])
candidate_y = torch.cat([y, candidate_y])

Masalah: data input bisa menemukan dirinya sendiri sebagai tetangga terdekat. Itu leakage.

Solusi kode: jika index tetangga sama dengan dirinya sendiri, jaraknya dibuat inf, lalu dibuang dari context.

8. FAISS dalam TABR, satu kalimat

“FAISS dipakai TABR untuk mencari top-k vektor training yang paling dekat dengan vektor input di ruang laten, lalu indeks tetangga itu dipakai untuk membentuk context.”
