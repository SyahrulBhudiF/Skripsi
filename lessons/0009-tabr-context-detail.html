TABR: Context Itu Apa Tepatnya?

Target: paham isi context, bukan cuma “tetangga mirip”.

Feedback

Jawaban kamu benar: retrieval cari data mirip, predictor menghasilkan skor, context berasal dari tetangga mirip.

1. Context bukan cuma tetangga

Context = informasi ringkas dari beberapa tetangga terdekat.

Di TABR, context dibentuk dari 3 bahan:

  1. Siapa tetangganya: indeks data train yang mirip.
  2. Label tetangga: target/y dari data train mirip.
  3. Perbedaan representasi: seberapa beda input dengan tetangga di ruang laten.

2. Alur context di kode

k input
candidate_k
FAISS search
context_idx
candidate_y
label_encoder
T(k - context_k)
context_x
distances, context_idx = self.search_index.search(k, context_size)
context_y_emb = self.label_encoder(candidate_y[context_idx][..., None])
values = context_y_emb + self.T(k[:, None] - context_k)
context_x = (probs[:, None] @ values).squeeze(1)

3. Arti kode itu

context_idx = tetangga mana yang paling dekat.

context_y_emb = label tetangga diubah jadi vektor.

k - context_k = beda input dengan tetangga.

probs = bobot kemiripan; tetangga lebih mirip dapat bobot lebih besar.

context_x = rata-rata berbobot dari informasi tetangga.

4. Analogi sederhana

Pasien baru mirip 3 pasien lama:

  • Pasien A: anxiety tinggi, sangat mirip → bobot besar.
  • Pasien B: anxiety rendah, agak mirip → bobot kecil.
  • Pasien C: anxiety tinggi, mirip → bobot sedang.

Context bukan cuma “mayoritas tinggi”. Context juga mempertimbangkan seberapa mirip dan apa bedanya pasien baru dari pasien lama.

5. Kalimat presentasi

“Context pada TABR dibentuk dari sampel training yang paling mirip. Model mengambil label tetangga, menghitung perbedaan representasi antara input dan tetangga, lalu menggabungkannya dengan bobot kemiripan. Context ini kemudian ditambahkan ke representasi input sebelum masuk predictor.”

Latihan

  1. Context berisi label tetangga saja atau label + beda representasi?
  2. Tetangga yang lebih mirip bobotnya lebih besar atau lebih kecil?
  3. Context ditambahkan ke apa?

Kunci: label + beda representasi; lebih besar; representasi input.
