TABR: Laten, Residual Add, Predictor

Target: kamu bisa jelaskan 3 istilah yang masih kabur: laten, residual add, dan predictor.

Sumber: official implementation third_party/tabular-dl-tabr-official/bin/tabr.py dan paper TabR: Unlocking the Power of Retrieval-Augmented Tabular Deep Learning.

1. Laten itu apa?

Laten = versi “kode angka” dari data mentah.

Misal data mentah pasien:

umur, jenis kelamin, nilai POC-ABS, fitur statistik, label anxiety, dst.

Data mentah ini belum nyaman untuk dipakai langsung. Encoder mengubahnya menjadi vektor angka internal:

z = [0.21, -1.03, 0.77, ...]

Vektor ini disebut representasi laten. Artinya: bentuk tersembunyi/internal yang menurut model mewakili data itu.

Di kode: x = self.linear(x) lalu x = x + block(x). Output x ini adalah representasi laten.

2. Kenapa perlu laten?

Karena retrieval lebih enak dilakukan di ruang laten.

Contoh: dua orang bisa punya fitur mentah beda, tapi pola anxiety mirip. Encoder belajar membuat mereka dekat di ruang laten.

Jadi model tidak cuma tanya: “angka mentahnya mirip?” tapi: “menurut representasi model, kasus ini mirip siapa?”

3. Residual add itu apa?

Residual add = simpan informasi lama + tambahkan informasi baru.

Di TABR:

x = x + context_x

x = representasi input asli setelah encoder.

context_x = informasi tambahan dari tetangga yang mirip.

Jadi model tidak mengganti x. Ia menambahkan context ke x. Ini aman karena identitas input tetap ada, tapi diperkaya oleh tetangga.

4. Context itu datang dari mana?

Input → z
Cari tetangga mirip
Ambil label tetangga
Hitung beda z
Gabung jadi context

Di kode:

  • context_idx: indeks tetangga terdekat hasil FAISS search.
  • candidate_y[context_idx]: label tetangga.
  • k[:, None] - context_k: beda representasi input dengan tetangga.
  • context_x: hasil gabungan context.

5. Predictor bisa predict gimana?

Predictor bukan “tahu sendiri”. Ia belajar dari training.

Selama training:

  1. Model membuat output skor.
  2. Skor dibandingkan dengan label asli.
  3. Loss dihitung.
  4. Bobot encoder, retrieval transform, dan predictor diperbaiki lewat backpropagation.

Setelah sering dilatih, predictor belajar pola: representasi final seperti ini biasanya anxiety tinggi atau rendah.

Di kode:

for block in self.blocks1:
    x = x + block(x)
x = self.head(x)
return x

self.head menghasilkan skor akhir. Untuk classification, skor ini disebut logits. Kelas dengan skor lebih besar menjadi prediksi.

6. Narasi presentasi 60 detik

“Pada TABR, data tabular mentah terlebih dahulu masuk ke encoder. Encoder mengubah data menjadi representasi laten, yaitu vektor angka internal yang merangkum pola penting dari data.”

“Representasi ini dipakai untuk retrieval, yaitu mencari sampel training yang paling mirip. Dari tetangga tersebut, model mengambil informasi label dan perbedaan representasi untuk membentuk context.”

“Context kemudian ditambahkan ke representasi awal melalui residual add. Artinya, informasi asli tidak dibuang, tetapi diperkaya dengan informasi dari sampel mirip. Setelah itu predictor memproses representasi final dan menghasilkan skor prediksi anxiety tinggi atau rendah.”

Latihan

  1. Laten itu data mentah atau kode internal?
  2. Residual add membuang x lama atau menambahkan context?
  3. Predictor menghasilkan apa sebelum jadi kelas?

Kunci: kode internal; menambahkan context; skor/logits.
