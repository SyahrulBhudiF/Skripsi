FAISS untuk TABR

Target: paham FAISS itu apa, cara kerjanya, dan kenapa dipakai di TABR.

Sumber utama: FAISS Getting Started, IndexFlatL2 docs.

1. FAISS itu apa?

FAISS = library untuk mencari vektor yang paling mirip / paling dekat.

Nama lengkapnya: Facebook AI Similarity Search.

Input FAISS adalah kumpulan vektor. Query juga vektor. Outputnya adalah tetangga terdekat dari query.

2. Kenapa TABR butuh FAISS?

TABR punya representasi laten k untuk input baru.

TABR juga punya banyak representasi kandidat dari data training: candidate_k.

Masalahnya: input ini paling mirip dengan data training yang mana?

FAISS menjawab itu dengan cepat.

3. Cara kerja FAISS versi sederhana

Buat index
Masukkan candidate_k
Query pakai k
Hitung jarak
Ambil top-k terdekat
self.search_index = faiss.IndexFlatL2(d_main)
self.search_index.reset()
self.search_index.add(candidate_k)
distances, context_idx = self.search_index.search(k, context_size)

4. Apa itu IndexFlatL2?

Index = tempat FAISS menyimpan vektor agar bisa dicari.

Flat = exact search. Ia membandingkan query dengan semua vektor kandidat.

L2 = jarak Euclidean. Semakin kecil jaraknya, semakin mirip.

Jadi IndexFlatL2 artinya: cari tetangga terdekat secara exact memakai jarak L2.

5. Output FAISS

FAISS mengembalikan dua hal:

  • distances: jarak query ke tetangga.
  • context_idx: indeks tetangga di data kandidat.

Di TABR, context_idx dipakai untuk mengambil:

  • representasi tetangga: context_k = candidate_k[context_idx]
  • label tetangga: candidate_y[context_idx]

6. Analogi

Bayangkan perpustakaan kasus lama.

  • Setiap kasus lama punya kartu ringkasan angka.
  • Pasien baru juga dibuatkan kartu ringkasan angka.
  • FAISS mencari kartu lama yang paling dekat dengan kartu pasien baru.
  • Kartu terdekat itu menjadi context untuk membantu prediksi.

7. Soal ABC

1. FAISS dipakai untuk apa?

  1. Menggambar grafik loss
  2. Mencari vektor paling mirip
  3. Menghapus fitur kosong

2. Pada IndexFlatL2, L2 berarti apa?

  1. Jarak Euclidean
  2. Jumlah kelas label
  3. Ukuran batch train

3. Output context_idx berisi apa?

  1. Nilai loss model
  2. Indeks tetangga terdekat
  3. Nama kolom dataset

4. Dalam TABR, FAISS mencari kemiripan antara apa?

  1. k input dan candidate_k
  2. label input dan label output
  3. gambar wajah dan ROI

5. Semakin kecil jarak L2, artinya?

  1. Semakin tidak mirip
  2. Semakin mirip
  3. Semakin banyak kelas
