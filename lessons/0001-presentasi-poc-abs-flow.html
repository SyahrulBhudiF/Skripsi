Narasi 60 detik

“Tahap ini dimulai dari Input ROI, yaitu area wajah yang sudah dipotong, seperti mulut, mata kiri, dan mata kanan. Untuk setiap ROI, sistem membandingkan frame t dengan frame t+1.

ROI lalu dibagi menjadi beberapa block. Pada tiap block, digunakan Phase-Only Correlation, yaitu teknik berbasis Fourier untuk mencari pergeseran lokal antar dua frame. Puncak korelasi menunjukkan arah dan besar pergeseran paling kuat.

Hasil pergeseran itu dibentuk menjadi vektor gerak. Dari vektor ini dihitung fitur X, Y, sudut θ, dan magnitude. Semua fitur itu kemudian disimpan sebagai representasi gerakan micro-expression per frame dalam file Excel.”

Mapping langsung ke kode

  • Input ROI: REGIONS + ROIExtractor
  • Frame t & t+1: baseline frame dibandingkan dengan frame berikutnya di event clip
  • POC: POC(baseline_gray[comp], gray, block_size)
  • Vektor gerak: Vektor(poc.getPOC(), block_size)
  • X, Y, θ, magnitude: block[1], block[2], block[3], block[4]

Latihan cepat

Tutup narasi di atas, jawab dari ingatan:

  1. Kenapa perlu membandingkan frame t dan frame t+1?
  2. POC mencari apa dari dua block ROI?
  3. Empat fitur akhir yang keluar dari tiap block apa saja?

Jawaban target: perubahan gerak antar frame; pergeseran lokal/puncak korelasi; X, Y, θ, magnitude.
